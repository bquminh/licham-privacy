# Chính sách bảo mật — Lịch Âm

Trang chính sách bảo mật của ứng dụng **Lịch Âm — Lịch Việt & Tử Vi**
(`com.bquminh.calendar`), phục vụ qua GitHub Pages để gắn vào Google Play
Console và App Store Connect.

Hai trang: `index.html` (chính sách) và `xoa-tai-khoan/index.html` (đường dẫn
yêu cầu xoá tài khoản khai trong mục An toàn dữ liệu của Play). Mã nguồn ứng
dụng nằm ở repo khác.
